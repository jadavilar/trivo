# Firmas de correo Trivo

Imágenes comunes de las firmas de correo. No cambiar los nombres de archivo: todas las firmas apuntan a ellos.

- `logo.png`: logo Trivo
- `instagram.png`, `facebook.png`, `linkedin.png`: iconos estilo Minimal
- `instagram-solido.png`, `facebook-solido.png`, `linkedin-solido.png`: iconos estilo Clásica
- `banda.png`: franja «Único portal exclusivo de proyectos inmobiliarios en Ecuador · Ver proyectos»

Para cambiar una imagen en todas las firmas, sube el archivo nuevo con el mismo nombre.
